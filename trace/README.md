# Trace, reading edition (vendored)

Generic reading-view code and styles from Trace, the evidence outliner that TraceCite comes from. The builder (`scripts/build-reading.mjs`) inlines these files.

- Paper-specific data files are empty stubs: `provided-context-data.js`, `online-context-data.js`,
  `source-context-data.js`, `table-evidence-data.js`.
- `source-passages.js` is a stub with the same interface and no correction.
- Fonts: Raleway and Nunito, under the SIL Open Font License (see `assets/OFL.txt`, `assets/nunito-OFL.txt`).
